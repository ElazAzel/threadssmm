# Ручной сбор видимых постов Threads

Необязательное расширение Chromium Manifest V3. Сбор запускается только кнопкой «Собрать видимые посты» в активной вкладке https://threads.com, https://www.threads.com, https://threads.net или https://www.threads.net.

## Установка и использование

1. Распакуйте скачанный ZIP. Откройте chrome://extensions (или edge://extensions).
2. Включите режим разработчика и выберите «Загрузить распакованное расширение».
3. Выберите папку `threads-capture`, содержащую manifest.json. В репозитории это `extensions/threads-capture`. Сборка и npm не нужны.
4. Откройте Threads самостоятельно и найдите нужные посты. Нажмите значок расширения, затем «Собрать видимые посты».
5. Проверьте JSON в предпросмотре. Скопируйте его или скачайте файл и импортируйте в локальном помощнике.

Если копирование запрещено браузером, текст выделяется для Ctrl+C / Cmd+C. Дополнительное разрешение clipboardWrite не запрашивается. При закрытии окна расширения выборка забывается; скачанные файлы и буфер обмена остаются под вашим управлением.

## Ограничения

Это DOM-эвристика, а не официальный API и не полная выгрузка ленты. Только элементы, пересекающие текущую видимую область окна, до 200 постов; никакой автопрокрутки, раскрытия текста или загрузки новых страниц. Частично видимый пост может содержать только часть текста. Нельзя использовать эту выборку для оценки всей аудитории или полной статистики. Вложенные цитаты и неоднозначные контейнеры могут быть пропущены. Изменения DOM Threads могут сломать сбор. Лайки, ответы и репосты не угадываются: всегда null. Дата берётся только из видимого time[datetime], иначе null. Автор определяется по канонической ссылке поста. Текст проверяйте вручную.

Формат: `{ "schemaVersion": 1, "posts": [{ "id": "…", "url": "https://www.threads.com/@author/post/id", "author": "@author", "text": "…", "publishedAt": null, "likes": null, "replies": null, "reposts": null }] }`.

## Приватность и разрешения

Только activeTab и scripting. Нет фонового обработчика, постоянных разрешений на сайты, внешнего кода, сетевых запросов, аналитики, чтения cookies, токенов, ключей, скрытого состояния приложения или форм входа. Скрипт читает обычный DOM только по вашему нажатию, не комментирует и не публикует. Полученный текст не отправляется автоматически в основное приложение или другие сервисы. Не импортируйте чужие приватные данные без права на их использование.

Проверки выполняются на искусственных HTML-фикстурах; работа на живом Threads не проверена. Для ручной проверки сравните экспорт с экраном, проверьте пустую страницу, скрытые и находящиеся за экраном посты, повторные ссылки и отказ копирования.
